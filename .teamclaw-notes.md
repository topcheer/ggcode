# Task notes: #5769 lanchat outbound secret-pattern false positives (2026-11-18)

Branch: teamclaw/task-teamauto-mwlh4pr3-f25cb737 (parent = origin/main deaff4b18, HEAD==origin/main at start).

## Root cause (empirically probed at parent before fixing)
- internal/agent/exfil_chain_check.go extractExfilSecretSnippets feeds off
  secretPatterns (secret_redact.go); the assignment_secret regex has NO word
  boundary before api[_-]?key, so TEST_API_KEY / testAPIKey match mid-identifier.
- ["'\s]*[:=]\s* crosses NEWLINES: bare "API_KEY=" at EOL records the NEXT
  line's identifier (e.g. ISSUE_5759_KEY_PINS_THE_FIX) as a secret-value
  fingerprint -> verbatim DIRECT alarm when a review message quotes the name.
  This is the exact R4-8 shape from the issue.
- Probe at parent: const testAPIKey = "test-key-1234567890abcdef" recorded a
  fingerprint and DIRECT-fired on a quoting lanchat message; TEST_API_KEY=
  dummy_value_... PROXIMITY-fired; real .env sk-ant key still DIRECT-fired.

## Fix (both issue mitigations, applied at the RECORD side)
1. Prefix whitelist exfilPlaceholderName: identifier ending at match start
   (exfilIdentifierBefore scans back over [A-Za-z0-9_-]) with case-insensitive
   prefix test/example/fake/dummy/sample/mock/stub/placeholder/fixture or
   ^issue[_-]?[0-9]+[_-] -> fingerprint suppressed (kills DIRECT + PROXIMITY).
2. Value-shape threshold for assignment_secret only: exfilPlaceholderShapedValue
   rejects single-case identifier-ish tokens (underscore = identifier glue,
   NOT a credential special); credential-shaped = mixed case OR non-identifier
   specials (-+/.=). Plus belt-and-braces: identifier-shaped value that itself
   carries a placeholder prefix is suppressed.
- Value-anchored patterns (AKIA/gcp/AIza/ghp_/glpat-/xox/sk-/JWT/PEM/bearer)
   are EXEMPT from both filters -> a real-shaped key under a TEST_ name still
   records and alarms (zz test TestIssue5769_RealKeyUnderPlaceholderNameStillAlarms).
   Layered effect: name suppression only drops unpatterned placeholder blobs.

## Verification
- 5/5 TestIssue5769_* PASS at fix head; all 17 TestExfilChain_* + redact +
  hardcoded tests unchanged-PASS; full go test -tags goolm ./internal/agent/ ok 53.3s.
- Pre-fix pin: zz_issue5769_test.go at parent deaff4b18 -> build failed
  (undefined: exfilPlaceholderName / exfilPlaceholderShapedValue) - compile pin.
- gofmt clean.

## Gotchas

  checkExfilChain from watcher_registry.go:104 (check); lanchat is only a sink
  name in exfilSinkTools - the whole detector lives in internal/agent, NOT
  internal/lanchat despite the issue title.
