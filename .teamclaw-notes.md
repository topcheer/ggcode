## Gotchas discovered

- Integration-test re-arm observation: NextTime returns a minute boundary STRICTLY after 'from', so polling job.NextFire.After(pinnedFireTime) deterministically detects fireJob's post-enqueue re-arm. Do NOT report the outcome inside the enqueue callback synchronously in tests: fireJob re-arms the next occurrence AFTER enqueue returns, and a synchronous auto-pause inside the callback would race the re-arm (production never does this - runs complete minutes later).
- fireJob debounces duplicate enqueues within 5s (s.lastEnqueue); tests driving two quick fires must delete the stamp between rounds.
- withDocSyncReminder keyword check is SUBSTRING-based ('docker' contains 'doc'); choose test fixtures without doc/readme/changelog substrings.
- write-tool gotcha: backslash-n inside Go string literals must be double-escaped through the tool layer or the file gets real newlines ('string literal not terminated').
- desktop/wailskit is part of the ROOT Go module; its tests run under go test ./desktop/wailskit/ (not covered by ci.yml's ./cmd/... ./internal/... - VERIFY_CI_FULL only).
