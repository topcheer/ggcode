## Semantics decided
- Announce is in-memory only: consumed when the carrying system prompt
  ships; a crash before that loses the announce line (never re-announces
  after restart) — durable VALUE survives, the one-time DELTA does not.
- Identical-value put: provenance refresh + audit "put-noop", NO announce.
- Announce framing rides INSIDE the changed entry's block (option (a)):
  block rewrites twice per change (announce version, then clean) but only
  the changed entry's block — untouched blocks keep the prefix cache.
- Announce line carries key + actor kind (self-describing, testable
  provenance per watchdog note 1).
- Writes need a durable sink; agents without session storage render only.
