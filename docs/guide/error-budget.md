# Error Budget（SLO 错误预算熔断）

agent 运行时维护一个滑动窗口（默认 20 次工具调用）的成功率预算（SLO 默认 85%）：

- **快烧警告**：窗口内失败率 > 2× 名义预算（30%）时注入一次告警——要求先重读失败输出、换方法再试
- **预算耗尽熔断**：失败率 > 名义预算且失败数 ≥6 时触发 breaker——注入升级提示，要求停止盲目重试、用 ask_user 请求人工裁决
- 熔断后保持安静（升级已请求，不重复打扰）；每个 run 重置

分层关系：compounding_failure = 单发提示层；error_budget = 动作预算层（本件）；tool_effectiveness = 数据建议层。三者互补不重复。
