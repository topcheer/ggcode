# v1.3.187 (Unreleased)

## Agent Intelligence

- **Adaptive reasoning effort allocation** — automatically adjusts reasoning effort per LLM turn based on the complexity of recent tool interactions. Routine operations (file reads, searches) use lower effort to reduce cost and latency, while complex operations (code edits, error recovery) use higher effort for better quality. Implements the per-request effort toggle pattern pioneered by Claude Opus 5 and GPT-5.5. Only activates when the user has NOT explicitly set effort via `/effort` or config — user override always wins.
  - Read-only tool sequences → low effort (faster, cheaper)
  - Code editing in progress → medium effort (balanced)
  - Error recovery / edit failures → high effort (thorough)
  - Effort display updated to show "auto (adaptive)" when no explicit effort is set
