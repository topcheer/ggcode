# v1.3.193

## New Write-Time Intelligence Checks (20 new checks)

### Code Quality & Design
- **Interface Design**: Fat interfaces (>7 methods), non-idiomatic naming, unnecessary abstractions, single-implementation interfaces
- **Struct Tag Consistency**: PascalCase JSON tags, redundant tags, inconsistent field coverage
- **Unkeyed Struct Initialization**: Positional struct literals that break silently on field reordering
- **Deep Control-Flow Nesting**: Cognitive complexity warning for nesting depth > 4

### Concurrency Safety
- **WaitGroup Misuse**: `Done()` without `defer`, missing `Add()`, `Add()` inside goroutine
- **Copylock Detection**: Sync types (Mutex, WaitGroup, etc.) passed by value instead of pointer
- **Channel Safety**: Double-close, send-after-close, close-in-loop
- **Loop Variable Capture**: Range variables captured in closures/goroutines without rebinding
- **Map Iteration Write**: Writing/deleting map keys during `range` iteration
- **Unrecovered Goroutine Panic**: `go func()` without `recover()`

### Runtime Safety
- **Slice Bounds Risk**: Unchecked indexing of `regexp.FindStringSubmatch`, `strings.Split` results
- **Unsafe Package Usage**: `unsafe.Pointer` arithmetic, deprecated `reflect.SliceHeader`, stored uintptr
- **Type Switch Exhaustiveness**: Interface type switches without `default` branch
- **Regex Compile in Loop**: `regexp.MustCompile` inside for/range loops

### Error Handling
- **Error Sentinel Comparison**: `err == sentinel` instead of `errors.Is(err, sentinel)`
- **Error Not Propagated**: Logging/handling error without returning it

### Security
- **Path Traversal Detection**: File I/O with unsanitized user input (Go/JS/Python)
- **Context Key Type Misuse**: `context.WithValue` with string/int keys instead of unexported type

### Resilience & DevOps
- **Retry Loop Quality**: Missing backoff or unbounded retry in network retry loops
- **Time Format Layout Error**: Non-Go time format strings (`YYYY-MM-DD` instead of `2006-01-02`)
- **Hardcoded Host/Port**: Bind addresses (`:8080`, `0.0.0.0`) instead of environment variables

## Infrastructure
- Default subagent timeout increased from 30m to 180m for complex research tasks
