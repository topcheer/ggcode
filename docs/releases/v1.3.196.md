# v1.3.196

## Bug Fixes

- **Fix panic on malformed env values** - `ggcode -v` no longer crashes with `slice bounds out of range [1:0]` when a single-quote character appears in environment variable values (e.g. `KEY='`). Added length guard in `parseEnvAssignment` and a warning message identifying the problematic variable. ([#7](https://github.com/topcheer/ggcode/issues/7))

## CI Improvements

- **Auto-sync winget-pkgs fork** - Release pipeline now syncs the winget-pkgs fork with upstream before submitting PRs, preventing stale-fork submission failures.

## New Intelligence Detectors

Five new metacognitive calibration detectors (zero LLM cost, deterministic):

- **Cross-Turn State Contradiction Detector** - detects when the agent reverses its root-cause diagnosis across turns without acknowledging the contradiction
- **Ungrounded Reflection Detector** - detects empty reflection loops where the agent "rethinks" without taking any verifying action
- **Plan Abandonment Detector** - detects when the agent declares a multi-step plan but abandons it partway through
- **Unverified Confidence Detector** - detects overconfident claims ("definitely works", "fix is complete") not backed by actual build/test/lint verification
- **Premature Success Declaration Detector** - detects when the agent claims task completion but then continues executing tool calls, revealing its self-assessment was wrong
