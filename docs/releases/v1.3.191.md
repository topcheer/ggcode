# v1.3.191

## Features

- **CI/CD pipeline status tool**: New `ci_status` tool lets the agent check GitHub Actions workflow results, list recent runs, and pull failure logs via `gh` CLI -- closing the push-to-CI-to-fix feedback loop.
- **On-demand code review**: New `review_changes` tool provides structured code review reports (CRITICAL/WARNING/INFO) for staged, unstaged, or all changes -- reusable diff scanning with commented-code and large-file detection.
- **Dependency vulnerability detection (SCA)**: Post-write check that scans `go.mod`, `package.json`, `requirements.txt`, `Pipfile`, `pyproject.toml`, and `Cargo.toml` for known CVEs when the agent edits them. First AI coding agent with write-time supply-chain security.
- **Disk space monitor**: Pre-run check warns when available disk space is low (2 GiB warning, 500 MiB critical) to prevent silent failures from disk exhaustion.
- **Environment variable drift detection**: Detects when variables declared in `.env.example` are missing from the local environment, preventing cryptic build/test failures.
- **Cron double-fire fix**: Timer reschedules from `job.NextFire` instead of `time.Now()`, preventing duplicate execution when the OS timer fires 1 second early.
- **Check registry refactor**: Replaced monolithic write-integrity function with parallel, language-aware check registry with panic recovery (50+ checks).
- **Crash recovery journaling**: Run-state journal detects crashed previous runs and alerts the user on next session start.
- **Orphaned background command detection**: Warns when background commands are started but their output is never checked.
- **Cross-run behavioral pattern detection**: Detects recurring tool-use patterns across runs for context-aware suggestions.
- **Cross-file impact analysis**: Analyzes symbol-level impact across files before edits to prevent cascading breakage.
- **Response quality scorer**: Per-response quality scoring for provider/model A/B comparison.
- **Project profile detection**: Auto-detects project language, framework, and build system, injecting concise profile into system prompt.
- **Removed post-write auto-format**: Eliminated `gofmt`/`goimports`/`prettier` auto-format that was corrupting versioned imports.

## Desktop Features

- **Window state persistence**: Remembers and restores window position, size, and maximized state.
- **System tray icon**: Quick actions menu with close-to-tray support.
- **Global hotkey**: Option+Cmd+G toggles window visibility from any app.
- **Session export**: Export sessions as Markdown or JSON.
- **Session switching shortcuts**: Cmd+Shift+[/] to switch between sessions.
- **System theme integration**: Real-time light/dark theme following OS setting.
- **Offline indicator**: Status bar shows network disconnection.
- **Always-on-top**: Pin window above other windows.
- **Zoom controls**: Cmd+/Cmd- for font scaling.
- **File drag-and-drop**: Native drag-and-drop file support.
