# v1.3.262

发布日期：2026-10-15

自 v1.3.261 以来 33 个提交（含 PR #4105–#4120）。聚焦：**subagent 委托导航**与 **pipe 临时 provider 模式**两大特性、睡眠期记忆再巩固（sleep-time compute）、best-of-N 准入账本、确定性故障注入层、A2A 委托声明、WebUI 增量流式渲染、OSC 7501 状态协议，以及死码清理三轮。

## 新增特性

### Subagent 委托导航（用户重点需求）
- **PR #4116** subagent delegation steering：插入消息智能分类（保守 miss-to-Addition 不打断在途 run）、子代理完成推送通知、spawn/wait 对称使用指引——主 agent 长上下文下主动拉起/接管子代理分工的行为质量提升（伴 InterruptionInsert 分类表用例）

### Pipe 临时 Provider 模式（用户重点需求）
- **PR #4118**（issue #4117）ad-hoc provider mode：`ggcode -p --llm-base-url ... --llm-model ...`（或 `GGCODE_LLM_*` 环境变量）直接指定模型+端点，**零 config 文件 I/O**（不读不写 ggcode.yaml）；协议自动推断（anthropic/gemini/openai 兼容）+显式覆盖；半对配置报错不静默

### 记忆与可靠性研究项
- **PR #4106**（sa-63）idle-window memory re-consolidation：空闲窗记忆再巩固（Letta sleep-time compute 思路）

- **PR #4108**（sa-65）`GGCODE_LLM_FAULT` 确定性故障注入层——agent 混沌测试基建（含行为测试）

### 可观测性与互操作
