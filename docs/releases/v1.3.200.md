# v1.3.200

## Highlights

- **Secret redaction architecture fix**: Redaction moved from agent internal processing to display layer only. Internal processing now uses plaintext throughout; masking only occurs at TUI/GUI/Mobile/IM display time.
- **Dead code cleanup**: Removed 23 unused agent intelligence modules and ANP (Agent Negotiation Protocol) -- net -10,397 lines of code that was never wired into the agent pipeline.
- **Guidance message optimization**: All 37 agent detector guidance messages trimmed to remove verbose filler (arXiv citations, generic advice, numbered steps). Messages reduced from 200-450 chars to 80-130 chars on average.
- **Context efficiency**: Per-turn guidance budget limiter (max 5/turn), detector sampling gate, and web_fetch truncation optimization reduce context pollution.

## Bug Fixes

- **Secret corruption fix**: Prevented agent from writing `REDACTED` markers into files when secret patterns appeared in tool arguments or file content.
- **nil_deref delta detection**: Fixed false positives caused by count-based detection instead of position tracking.
- **Metacognitive monitor deadlock**: Fixed reentrant lock acquisition in `evaluateConsistency`.
- **Bare goroutine safety**: Replaced all bare goroutines with `safego.Go` for panic recovery.

## Breaking Changes

None. All removed modules were internal dead code with zero external usage or API surface.
