# v1.3.263

发布日期：2026-10-16

自 v1.3.262 以来 64 个提交（含 PR #4130–#4205）。聚焦：**session journal tombstone 机制**（vision-fallback 双 turn 治本）、**stale-observation 再验证升级**、**ggcode config 子命令**、**recall_compacted 紧凑内容再检索**，以及三轮测试覆盖大提升（markdown 55.9%→95.1%、auth 57.3%→65.3%、update 60.4%→72.7%）。

## 新增特性

### 会话持久化一致性（用户重点需求）
- **PR #4205**（issue #4200）session journal `message_remove` tombstone：append-only JSONL 增加删除事件（scan-order 语义），loadSession 双端弹出被撤销的原始 user 消息——vision-fallback 重试后 resume 重放不再双 turn、原始图片不再重入上下文复发 vision 400

### CLI 与上下文
- **PR #4147** `ggcode config` 子命令：打印生效配置（secrets 掩码），排障不再手翻多层 YAML
- **PR #4145**（issue #4144 相邻族）`recall_compacted`：已压缩内容按需再检索，compact 后旧细节可回捞
- **PR #4152** stale-observation re-verify escalation：陈旧观察的升级再验证（PoS belief-trapping 恢复）
