# v1.3.278

发布日期：2026-11-10

本轮核心是**守护层的精度收敛**（#5289→#5342 守护家族三轮回归全闭）与 **webui 前端能力补全**（#5277 系）：vendor 端点字段级管理、流式 markdown 渲染、以及一轮模型能力同步的本地修正层。

## 守护层（rm_rf / irrev_gate）

- **pflag 等号形式识别**（#5289）：`gh api --method=DELETE`、`--field=k=v` 等等号形式旗标此前绕过不可逆闸（只匹配空格形式），现同套检查覆盖。
- **平台门控路径折叠**（#5290）：`normalizeFilePath` 不再无条件 ToLower——大小写敏感文件系统上 Foo.go 与 foo.go 不再被误合并为同一追踪键（消除假编辑重复/假未读告警）。
- **rm 词法门 heredoc 语义**（#5315→#5328→#5342 三轮）：①heredoc 正文剥离只对文本接收者生效，bash/sh/python3 等解释器 heredoc 内的递归强删保持可见（#5328 修复 #5315 引入的漏报）；②wrapper 前缀（sudo/nohup/xargs/timeout 及其参数）剥离后仍命中 rm 词（#5342 修复特权/批处理调用盲区）；③文本提及（echo/grep 参数/日志正文）持续不误报。

## webui

- **React+Vite SPA 重建**（#5277 系）：chat-first 全新前端（Composer/@mention/流式渲染/会话侧栏），vendor 端点字段级管理表单（保留未投影字段，修复 PUT 全量替换静默清空 APIKey 等约 21 字段的契约缺陷 #5293/#5294）。
- **设置页保存**（#5298）：PUT /api/config 白名单合并落地，保存按钮不再 dead-on-arrival。
- **离线补发**（#5300）：Composer 断线期间输入不再禁用，兑现"重连后补发"承诺。
- **桌面端草稿隔离**（#5308）：切换会话不再串写草稿键。

## 模型能力

- **本地修正层**（#5332 系）：models.dev 周同步引入 capability override 表（含审计字段），上游 o3-mini 视觉误标回流由 drift-guard 拦截后可本地修正，周任务转绿。

## 基础设施

- **cron one-shot 远未来告警**（#5353）：NextFire 落地超 90 天的 one-shot 任务发响亮警告（year+1 陷阱二次复发的根治）。
- **tunnel 监视 goroutine 收编 safego**（verify-ci 闸门修复）：webui 隧道关闭监视纳入崩溃保护。
- **irrev_gate 裸关键字透传**（#5339）：for/do/then 等控制流字不再透传成命令词。

## Upgrade notes

- 无破坏性变更；webui 前端为内置资源，升级即生效。
- `model-caps` 周同步新增 capability override 审计表（scripts/sync-model-caps.go），上游修正后可删除对应条目。
