# ggcode v1.3.270

## Highlights

- Provenance and audit upgrades across delegation, permissions, and context visibility: sub-agent results now carry an external-source provenance header, policy-rule denials enter the audit ledger, and `/context` gains a provenance breakdown plus six more tracked peer channels.
- Audit ledger hash hardening: attribution fields are field-tag encoded, closing the slot-sliding collision class where values could move between InvariantID/Peer/TaskID without tripping the chain.
- Delegation reliability: async delegate contexts no longer leak; the macOS/desktop and tmux/terminal surfaces got another round of cross-platform fixes.

## Fixes and improvements

- glob: wildcard prefixes in `**` patterns (`*/**/*.go`) expand before walking instead of silently matching nothing (#4705)
- provider: non-streaming Chat backfills completion-only usage so compaction cost accounting no longer understates the prompt side (#4664)
- config: legacy vendor keys preserved when the target endpoint already carries its own key (#4678)
- tool: quoted diff paths (spaces/non-ASCII) flow through every header consumer; binary detection and commit plans no longer drop them (#4683, #4686)
- agent: description fallback survives literal `null` arguments (#4693); #4563-family backfills; verify-gate predicate alignment (#4661)
- tmux: pane store quarantines-and-rebuilds on corruption instead of wedging (#4681); shell commands use POSIX single-quoting (#4680)
- TUI: history search appends real text instead of keystroke names so multi-word queries work (#4731); feishu auto-enable bind confirms success (#4724); /context provenance + channel alignment (#4677, #4720, #4722)
- session: timestamp backfill and idle-runner CAS guards (#4670, #4672); enum-correction panic guard (#4700)
- desktop/mobile: X11 windowmove chain (#4696), tail-preserving failure fallback (#4690), URL phantom-warning fix (#4688)
- feat: delegation provenance header (#4716), policy_denied audit status (#4701)

## Upgrade notes

- Audit chains written by older builds still Verify (the all-empty attribution shape is byte-identical); entries with attribution fields hash under the new field-tagged encoding.
- `audit report` now lists `policy_denied` counts alongside user approvals.
- wait_agent results prepend a `[provenance: ...]` header when the sub-agent used external-source tools; output is unchanged otherwise.
