# v1.3.283

Release notes for ggcode v1.3.283 (190 commits since v1.3.282).

## Infrastructure (breaking toolchain bump)

- **Flutter 3.47.9 -> 3.50.0 toolchain** (#5696): Gradle wrapper 8.14.3 ->
  9.9.1, AGP 8.11.1 -> 9.5.0, `kotlinOptions{jvmTarget}` migrated to the
  `compilerOptions` DSL (Gradle 9 requirement), CI FLUTTER_VERSION pins synced
  in `ci.yml` + `mobile-release.yml`. Flutter 3.50 requires Gradle >= 9.3.1;
  AGP 9.5 requires >= 9.6.0 and JDK 17 - release pipelines verified on the new
  baseline (mobile-release uses temurin 17).
- **Weekly deps bump** (#5694): 9 Go root modules (chromedp, whatsmeow,
  etunnel, goja, forwarder, lipgloss/v2, x/image, x/mod, cdproto) + 5 desktop
  npm minors (vite, marked, jsdom, lucide-react, plugin-react). Desktop go.mod
  synced transitively.
- **Material deprecation advisory**: `analyze` reports 16 new info-level
  `material.dart -> material_ui` deprecations on 3.50 (progressive migration
  path, non-blocking; CI mobile-test runs tests only).

## A2A / Introspection
