# v1.3.194

## Runtime Intelligence

- **Tool Output Claim Verification**: Detects when agents misinterpret tool outputs as successful when they actually contain hidden failure signals (exit code 1 in output text, panics, "file not found", empty results). Based on AgentRx research (Microsoft Research, 2026). Zero LLM cost, non-blocking.
- **Tool Effectiveness Tracker**: Tracks runtime tool success rates across the session. When tools consistently fail, injects guidance to try alternative approaches.

## New Write-Time Intelligence Checks (15 new checks)

### Security
- **Sensitive JSON Exposure**: Struct fields with sensitive names (password, secret, token) without `json:"-"` tag
- **SQL Injection Detection**: String concatenation in SQL queries with user input (OWASP A03:2021)

### Concurrency Safety
- **Global Variable Race**: Global variables read/written from goroutines without mutex protection
- **Range Over Nil Pointer**: `range` over potentially nil slice/map pointers

### Code Quality
- **Empty Error Check Body**: `if err != nil {}` with empty body - error checked but not handled
- **Ignored Append Return Value**: `append()` result not assigned back to variable
- **Float Equality Comparison**: Direct `==`/`!=` on float64 values (IEEE 754 precision issues)
- **Deferred Call Argument Evaluation**: Deferred functions with arguments evaluated at defer time, not execution time
- **Naked Return in Long Function**: Naked returns in functions >20 lines (readability hazard)
- **Ignored Close() Error**: `defer file.Close()` without checking error for writable resources
- **Value Receiver Mutation**: Value receiver methods that mutate via pointer (incorrect usage)
- **init() Side Effects**: `init()` functions performing I/O, network calls, or global state mutation
- **Constant Conditional**: `if true`/`if false` with literal boolean conditions
- **Unused Function Parameter**: Exported function parameters never referenced in body
- **Infinite Loop Without Exit**: `for {}` loops without break/return/panic exit paths

## Refactoring
- Reduced cyclomatic complexity in 3 check functions (checkDeferArgEval, nrInspectStmt, checkValueRecvMutation)
