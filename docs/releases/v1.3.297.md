# ggcode v1.3.297

## Highlights

- **Desktop: Chinese input no longer sends half-composed text, and approvals can no longer be granted by reflex.** A review of the desktop and mobile clients (`docs/reviews/desktop-mobile-ux-motion-review-2026-11-27.md`, 43 desktop + 21 mobile findings, each with a file:line) found two keyboard hazards in `ChatView`/`ApprovalDialog`: `Enter` during an IME composition sent the message and `Escape` cancelled the running agent, and the tool-approval dialog listened for `Enter` on `window` from the moment it opened - a user typing in the composer when an approval appeared approved a `run_command` by pressing Enter. Both handlers now ignore keys during composition (`isComposing` / keyCode 229); the approval dialog takes focus on mount, traps Tab, ignores keys outside itself and during its first 400 ms, and treats `Enter` on a focused button as that button's native action only. Pinned by the new `ApprovalDialog.test.tsx`.
- **Desktop: `⌘+` / `⌘-` finally zoom, `⌘8` finally opens Scheduled Tasks, light mode becomes readable, Mermaid diagrams render, streaming follows again.** The zoom hook set `html{font-size}` while every size in the stylesheet is px (0 `rem`), so the status bar said "110%" and nothing moved - it now applies CSS `zoom` on `<body>` and the competing `--font-size-base` keyboard system is gone. `--text-tertiary` carried 10–12 px metadata at 1.8–3.0:1 contrast in both themes (now 4.6–5.6:1), light-theme danger text was `#f87171` at 2.3:1 (now `var(--color-error)`), eight referenced-but-undefined CSS variables (`--color-hover`, `--border-color`, …) made hover backgrounds transparent and are now defined, the Windows/Linux window painted dark on every launch (real `AppsUseLightTheme` / `gsettings` detection plus a pre-paint theme script), the Mermaid effect was keyed on the session only so streamed diagrams never rendered, a global `scroll-behavior: smooth` made the auto-follow lag and then switch itself off, user bubbles sat flush left because `.message-row` was not a flex container, a 10-second timer yanked the view back to the bottom while the user was reading, and the nav rail labelled both LAN Chat and Cron `⌘7`. All fixed.
- **Desktop: streaming re-renders once per 30 ms instead of once per token, and chat HTML is sanitised.** `useStreamBuffer` existed since the July streaming-UX research but was never wired into `ChatView`; it now batches text/reasoning deltas with a demand-driven timer (no idle rAF loop, flushes when the tab hides), `appendBufferedChunks` applies a batch in one state update, highlight.js results are cached by (language, text) with language auto-detection off, and every `dangerouslySetInnerHTML` sink (markdown, inline SVG, LAN chat) goes through DOMPurify - model, tool and LAN output reached the WebView unsanitised, where `window.go.main.App` is reachable.
- **Desktop: a motion and token layer instead of 36 hand-written `0.15s` transitions.** `App.css` now defines `--dur-micro/base/enter/exit/emphasis`, `--ease-standard/decelerate/accelerate`, `--shadow-sm/md/lg`, `--z-*` and `--text-*`; dialogs and menus fade+scale in (`.dlg-backdrop`/`.dlg-enter`), toasts animate out instead of popping, the sidebar slides (and stays mounted), toast progress uses `transform: scaleX`, user rows enter with `.msg-enter`, the streaming caret is drawn at the end of the text, `:focus-visible` no longer mutates the focused element's shape, and the StatusBar context pill / AskUser option rows are keyboard-operable. Welcome cards use lucide icons instead of emoji. Inter and JetBrains Mono are bundled (8 subset files, 243 KB, OFL) with Segoe UI / PingFang / YaHei / Noto CJK fallbacks; the Google Fonts CDN link and the unused Nunito file are gone.
- **Mobile: light theme, system back, streaming cost, and a motion spec.** Shell/ANSI output was invisible on the light palette (default colour `#E5E7EB` on `#EAECF2`, 1.1:1); the QR scanner was a bool toggle on `home`, so the back gesture exited the app; every streaming chunk wrote provider state twice and rebuilt the whole list. Now: palette-driven ANSI colours, `PopScope` on the scanner, per-message chunk coalescing (16 ms, done frames flush the tail), a 350 ms debounce on the live-projection capture, keyed `RepaintBoundary` rows. `AppMotion` (micro/base/enter/exit/emphasis + curves, zero under "reduce motion"), `AppFonts` (monospace fallback for iOS), `onAccent` text on the user bubble and primary buttons (was 2.25:1 Midnight / 2.85:1 Light), `ColorScheme.fromSeed` with the full surface container set, `AnimatedSize` on tool results / code blocks / reasoning / subagent cards / workspace groups, an `AnimatedSwitcher` send↔stop button, fading scroll-to-latest FAB, sliding approval card, Connect→Chat fade-through, the tool-card glow no longer rebuilding the whole card every frame, a multi-line composer (1–6 lines; `Enter` inserts a newline), haptics for approve/deny/submit/interrupt/copy, theme-following status bar icons, a 600×600 threshold for the two-pane rail (landscape phones), a dark iOS launch screen, 32–40 px targets and Semantics labels, and ten new translation keys.

## Fixes and improvements

- desktop (ChatView): IME guard on Enter/Escape; cancel resets streaming state locally instead of waiting for `run_done`; pasted images reset on session switch; scroll position restore wired (`scrollRestorePendingRef` was set nowhere); search scrolls only when the active match changes; Mermaid follows the active theme; code-block Copy/Copied/Expand/Collapse are i18n'd in 13 locales; `chat.cancelled` system row
- desktop (ApprovalDialog): focus trap, 400 ms grace period, IME guard, Enter on a focused button is native-only, focus returns to the previous element on close
- desktop (theme/CSS): dead `:root` block and 91 lines of unused streaming CSS removed; duplicate scrollbar rule set collapsed into App.css with a contrast-corrected thumb; markdown links use `--color-info` (7.5:1 dark / 5.2:1 light); `⌘⇧T` goes through `useTheme`; `--topbar-height` matches the 36 px bar
- desktop (Layout/NavRail): `⌘8` opens Scheduled Tasks, rail tooltips use the platform modifier; sidebar width animates; ContextMenu/ShareDialog danger colours use tokens; AboutDialog has `role="dialog" aria-modal`
- desktop (Go): `appearance_windows.go` reads `AppsUseLightTheme`, `appearance_linux.go` reads `gsettings`/`GTK_THEME`, other platforms default to light; window background follows the OS on every platform
- mobile: approval/session-rail/subagent colours map to palette roles; Connect is the primary action and disabled until a URL is entered; free-form `ask_user` answers auto-grow (2–6 lines); thumbnails decode once and cache (`cacheWidth`, `gaplessPlayback`); the app bar/tab close/copy targets are 32–40 px with labels
- docs: `docs/guide/desktop.md` (zoom, `⌘7`/`⌘8`, IME, approval keyboard contract, bundled fonts), `docs/guide/mobile.md` (multi-line composer, scanner back, Connect, motion, haptics), review report with an implementation-status section
- tests: frontend 156/156 (`useStreamBuffer` timer semantics, `appendBufferedChunks`, body zoom, toast exit, DOMPurify policies, ApprovalDialog keyboard contract), wails app vet + darwin/windows/linux cross-build + tests, Flutter analyze clean and `flutter test` 145/145 (`chat_stream_coalesce_test.dart`; widget tests pump through the Connect↔Chat cross-fade)
- release prep: `make sync-model-caps` was run and its diff was **rejected**, as for v1.3.293–v1.3.296 - upstream models.dev still lists `glm-5.4` with a 1,000,000 context window (the built-in row from #5926 pins 1,048,576) and still drops the W47 calibration row `claude-opus-4.7`, so the regen fails `TestInferContextWindow_KnownModels` and `TestWeeklyCalibrationW47`. The capability table therefore ships unchanged; re-run the sync once the upstream rows agree with the pinned values

## Upgrade notes

- **Desktop `⌘+` / `⌘-` now scales the whole window** (CSS zoom, 70 %–180 %). Users who had set a per-install `ggcode-font-size` in an earlier build keep the default; zoom is persisted through `SetFontZoom` as before.
- **Desktop `⌘8` opens Scheduled Tasks**; `⌘7` continues to open LAN Chat. Shortcuts tooltips show `Ctrl+` instead of `⌘` on Windows/Linux.
- **Approval dialogs ignore the keyboard for their first 400 ms** and only respond while focused; `Enter` still allows, `Shift+Enter` always allows, `Esc` denies.
- **Mobile composer is multi-line**: `Enter` inserts a newline and the send button (or the keyboard's send action on the last line) sends. Previously `Enter` submitted a single-line prompt.
- **Mobile `Connect` is disabled until a URL is entered**; pairing via **Scan QR Code** is unchanged. The system back gesture on the scanner now closes the scanner instead of leaving the app.
- **Desktop fonts are bundled**; no network access is needed on first launch and Chinese text uses the platform's CJK UI font (PingFang SC / Microsoft YaHei / Noto Sans CJK SC).
- **No config changes**; the capability table ships unchanged (see release prep above).
