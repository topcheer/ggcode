# v1.3.282

Release notes for ggcode v1.3.282 (issue-count auto-trigger: 114 closed since #5464 baseline).

## Tooling / Agent loop

- **web_search degradation advisory** (#5578, #5579): sustained empty-result
  web_search calls now carry an explicit `[search-degraded]` advisory after 3
  consecutive backend-level empties, telling the agent to stop blind retries
  and switch to `web_fetch` on canonical URLs; one-time recovery note when the
  backend resumes.
- **Search degradation counter correctness** (#5580, #5581): the counter now
  judges on pre-filter backend results (`backendTotal`); domain-filter empties
  return an explicit `[search-filter-empty]` widen-the-filter hint instead of a
  misleading backend-degradation advisory.
- **Daemon goroutine guard** (#5583): the `--etunnel` auto-start tunnel
  goroutine is wrapped with `safego.Recover` so a panic in tunnel control
  cannot take down the daemon process.

## Config / Memory

- `memory.curator.dry_run_rounds` / `dry_run` flags wired into the memory
  sweep (#5527).
- Weekly model caps sync from models.dev (#5571).

## WebUI / Desktop

- `--etunnel` flag auto-starts the WebUI public tunnel and prints URL + QR
  (#5567); QR code for et tunnel URL + mobile scan-to-open (#5565).
- Collapsible right pane (desktop) + mobile-app logo; `/icon.png` served from
  the embedded dist instead of the SPA fallback (#5568/#5570).
- Subagent mailbox messages are now consumed between agent-loop iterations
  (#5569) instead of stalling until the loop exits.

## Mobile

- Unified web-URL routing across ALL connect entries (#5566).

## CI

- web packageManager pinned to pnpm@9.15.9; corepack runs from `web/` so the
  pin applies (#5568 follow-ups).
