# ggcode v1.3.286

## Highlights

- **Persistent teams (swarm).** Teammates now survive ggcode restarts (#5830, folding the #5829 design): P0 cross-instance safety (owner lease, random teammate IDs, restore-only board entries), P1 per-teammate journals, and P2 manifest/restore so a fleet comes back with its task board intact.
- **Swarm restore hardening.** Restore no longer rewrites the manifest from a stale in-memory copy (which erased rebound sessionFiles), and restore upsert now preserves `lastResultSummary`.
- **ctxstats prefix-drift sampler (#5812).** Detects prompt-prefix drift between turns; the `ctx-sample` marker is documented in the guide.
- **prompt-cache head/tail split (#5807).** The stable system head is now cached separately from the per-prompt turn tail, improving cache reuse across turns.
- **internal/tool data races cleared (#5825).** Shared `Cmd.Wait`, shared stderr buffer, and an unlocked `Status` read fixed.

## Fixes and improvements

- feat(swarm): persistent-teammate enhancements — early-compact, done-mail, `lastActiveAt` (#5822); early-compact is now config-owned with `teammate_early_compact_ratio` (0 disables) (#5828)
- fix(tool): iOS simulator frontend compatibility — DeviceHub fallback chain (#5820)
- fix(im): reset QQ gateway session/seq on workspace rebind (#5805)
- fix(ci): wire the ggcode-relay module into CI and drop deprecated npm/pip install anchors (#5733)
- chore(config): weekly model capability sync from models.dev (this release carries today's refresh of context-window / vision tables)
- docs: persistent-teams guide and multi-agent-modes cross-reference, ctx-sample marker guide, model-routing case notes

## Upgrade notes

- `swarm.teammate_early_compact_ratio` is now owned by config; set it to `0` to disable teammate early-compaction (previously a hardcoded default). See the swarm yaml example.
- Restored teammates recreate their board entries in restore-only mode; see the persistent teams guide before relying on cross-restart fleets.
- No mobile app changes in this release.
