# ggcode v1.3.292

## Highlights

- **The in-loop guidance injectors are gone (the #5924-#5944 trim).** `internal/agent` had grown ~150 heuristic "detectors" that watched the tool loop and injected bracketed reminders into the model's context (`[Verification reminder]`, `[Error Cascade]`, `[Overseer:]`, progress checkpoints, delegation coaching, plan-drift nudges, ...). In real sessions a dozen could fire for a change that was building and passing, several contradicting each other. Everything whose only output was a nudge was removed (~20k lines with their tests); `injectGuidance` / `guidanceEmit` are now hard no-ops so a stray caller can never reach the transcript. What deliberately stays is correctness and safety signalling, each rare and specific: destructive-git-command warnings, post-write integrity checks, non-atomic tool outcome notes, batch-edit conflict warnings, content checkers on write, the self-modification guard, the stop-before gates (evidence, research-report, goal-finish, outstanding steps, incomplete todos, self-review), auto-verify / lint feedback, low-disk and resumed-session dirty-file notices, and the shared-workspace iron rules. Record of what was cut, what stayed and why: [`docs/design/guidance-injection-trim.md`](../design/guidance-injection-trim.md).
- **`code_search` index loop closed (#5945).** The background BM25 index now stays fresh in every mode: edits made through any agent (TUI, `--print`/pipe, daemon, ACP, A2A) mark the touched files dirty and rebuild incrementally after a 3 s debounce - before, only the TUI did, so headless sessions served stale results until the 5-minute scan. The periodic scan compares against the in-memory index instead of re-parsing the disk cache every tick (and no longer re-tokenizes the whole tree forever when the cache was discarded for size). A tree with nothing indexable is a terminal state (`code index is empty` with a hint to use `grep` / `search_files`) instead of an endless "being built, try again"; files that grow past the 256 KB cap drop out; the first search on a cold start waits up to 2 s for a warm-cache build instead of costing a model round-trip. New user guide: [`docs/guide/code-index.md`](../guide/code-index.md).
- **Every turn ends with a finished-at line (#5946).** The TUI closes each agent turn with a system line carrying the wall-clock time - `Finished at 2026-11-24 09:08:07` (`Canceled at` / `Failed at` for the other outcomes) - so if you step away for hours you can see when the work stopped. Localized in all 10 UI languages; also reaches the mobile tunnel.
- **Swarm: finished tasks stay finished after a restart (#5927).** The team board is now persisted on every mutation, not only on leader-issued `swarm_task_*` calls: the teammate idle loop's claim / complete / rollback updates never reached `board.json`, so a restore re-claimed and re-ran work the user had already received. The master/teammate review loop is closed (#5940), and teammates no longer carry `lanchat` (#5918) - the tool dials the LAN under the leader's seat identity, so a worker could send external messages impersonating the main agent; workers report via `report_to_leader`.
- **glm-5.4 is a built-in model (#5926)** and the model-capability table got its W48 weekly sync (#5922).
- **ggcode.dev rebuilt (#5933-#5936)** - real product media, a motion system and a 3D hero, Lighthouse 98/97/100/100, and a configurable base so the GitHub Pages project site builds.
- **TUI decluttered (#5938, #5939).** The sub-agent "follow" panel (per-agent viewport, chip strip, Ctrl+N / arrow-key follow branches) and the external tmux / iTerm2 / kitty pane package are removed (-3.8k lines); the sidebar IM and MCP sections show a summary line only (`N adapters • N healthy`, `N up • N pending • N failed`), the per-server / per-adapter detail stays in `/im` and `/mcp`.

The capability table therefore ships as of W48 (#5922); re-run the sync once upstream carries glm-5.4.
- docs: synced with the trim (#5941 and the follow-up doc sweeps) - and this release also corrects what a full audit found still describing removed code: the "Delegation Orchestration Intelligence" section of the multi-agent guide, the `extpane` / `loop_detect` / `playbook` / `budget_guard` / `cache_keepalive` rows of the ARCHITECTURE optimization stack, the `Ctrl+X` key description (tmux action menu), and status banners on `plan-repair.md`, `uncertainty-calibration.md`, `bgorphan-detection.md` and `context-engineering-gates.md`

## Upgrade notes

- **No config changes.** If a workflow relied on in-loop reminders to steer the agent, that steering now has to come from the prompt, the tool results or the stop-before gates - by design; see the trim record above before re-adding one.
- **TUI**: `Ctrl+N` no longer enters a follow view and the external terminal panes are gone; `Ctrl+X` opens the tmux action menu when running inside tmux.
- **`code_search`**: in a tree with nothing indexable you now get a definitive "code index is empty" instead of "being built"; a cold first call may block up to 2 s. Raise `GGCODE_CODE_INDEX_MAX_TERMS` (negative = unlimited) or start ggcode inside a single project if the term budget truncates the index.
- **Teammates** no longer have the `lanchat` tool; use `report_to_leader`.
