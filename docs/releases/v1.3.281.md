# ggcode v1.3.281

## Highlights

- **New: `/et login`** — browser authorization for the etunnel public tunnel. Logs the account in via the SDK loopback flow and persists the API token, plan and custom-domain list; the next `/et on` uses the account credentials. Free accounts now correctly stay labeled "free" (plan label comes from the login receipt, not from token presence).
- **P0 fix: the LLM could receive zero tools.** A regression in the agent chat-turn refactor dropped the `toolDefs` parameter, leaving the model with an empty toolset (#5549). Also restores the empty-counter reset on productive tool turns.
- **Cross-session constraint anchors** — durable user constraints are persisted and enforced across sessions, closing the persona-drift P0. The agent also gains a persistent self-model (durable skills, declared limits) injected into delegation prompts.

## Fixes and improvements

- fix(agent): fulfillment-gate exempts verbs inside quoted references (#5554) — fewer false restart gates.
- fix(agent): injectable idle-maintainer sweep interval + busy-resident cap (consolidate at least every 6h) (#5497).
- fix(swarm): Manager-level BoardRoot isolates board persistence (#5540).
- fix(config): merge gate strips command wrapper and timeout duration args (#5418).
- fix(tui): preserve line structure in approval command preview (#5526).
- feat(agent): sawtooth exponential backoff for rate-limit retries.
- etunnel: SDK v1.2.0 → v1.6.8 (login flow + reconnect machinery); #5561 login goroutine leak fixed.

## Upgrade notes

- No breaking config changes. `/et login` requires the tunnel server's `/auth/cli/*` endpoints (public server already provides them; SDK default server unchanged).
- Static model-capability table refreshed (context windows / vision flags) via `make sync-model-caps`.
