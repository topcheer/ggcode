## 在线研究来源
1. **arXiv:2609.00006** "Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents"（2026-07，11 个生产 harness 源码研究，29 patterns / 13 observations / 18 recommendations）
   - 关键发现：skills 采纳率超过 MCP（9/11 vs 8/11）；**没有任何生产 harness 用向量检索**（全用 grep/tree-sitter/BM25——ggcode 的 BM25 路线正确）；行为策略从 prompt 散文迁移到结构化配置；ACP 装机 6/11 且出现第三角色 harness hosting；loop 本体自 SWE-agent 以来无本质变化，复杂度都在安全/UX/传输/扩展。

## 本轮实施：User-Directed Compaction（/compact [focus]）
- **Gap**：`handleCompactCommand()` 原来不接受任何参数；2026 研究核心实践是定向压缩（"Compact, preserving X" vs 泛化 "Compact this conversation"）。ggcode 仅有预先 `/pin`，缺"当下定向"入口。
- **实现**：`Manager.SummarizeWithFocus(ctx, prov, focus)`（`Summarize` 保留为空 focus 包装）；focus 非空时向摘要 system prompt 追加 "User Compaction Focus Directives (HIGHEST PRIORITY)" 段落（用户指令优先于默认结构）；TUI `/compact <focus>` 通过 `strings.Join(parts[1:], " ")` 传入；completion args 提示 `[focus]`；docs/guide/getting-started.md 更新。
- **验证**：`go build -tags goolm ./...` 通过；`go vet` 干净；gofmt 干净；context 包 Summarize 系列测试 + TUI Compact 测试 ok。新增 `internal/context/summarize_focus_test.go`（focus 注入 / 空 focus 不注入回归 / SummarizeWithFocus 端到端透传）。
- **提交**：a271b751b @ r122-frontier（已推送 origin）。
